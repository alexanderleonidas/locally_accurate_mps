# Locally Accurate MPS Approximations for Ground States of 1D Gapped Local Hamiltonians – Numerical Verification and Tightening of Bond Dimension Bounds

This repository contains the code and data for the corresponding master thesis reserach by Alexander Leonidas. The study investigates the accuracy of Matrix Product State (MPS) approximations for ground states of one-dimensional gapped local Hamiltonians, providing numerical verification and tightening of chain-length bounds.
